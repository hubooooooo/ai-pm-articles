# Third-party assets

## Shadow Hand E3M5

Original model and assets: Shadow Robot Company.

Distribution: [Google DeepMind MuJoCo Menagerie, shadow_hand](https://github.com/google-deepmind/mujoco_menagerie/tree/main/shadow_hand).

License: Apache-2.0, reproduced in `SHADOW_HAND_LICENSE.txt`. The original model description, README and meshes are preserved in `_prototype/three-hands/vendor/shadow_hand/` in the source repository.

Changes: geometry indexed and quantized for browser delivery; original kinematic hierarchy converted to browser scene data; custom joint poses, composition, camera, line rendering and animation added for this website.
